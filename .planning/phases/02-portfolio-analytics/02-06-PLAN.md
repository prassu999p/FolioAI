    **Family-total analytics row:**
    - Fetch holdings for ALL holders in the family using existing Phase 1 data
    - Aggregate: total_aum = sum of current_value across all folios/holders
    - Aggregate: total_invested = sum of total_invested across all holders
    - Aggregate: gain_loss = total_aum - total_invested
    - Aggregate: gain_loss_pct = (gain_loss / total_invested) * 100

    Implementation approach — use the holder-level holdings already fetched for each holder card, or add a single family-level query. Prefer a single query for efficiency:
    ```typescript
    // Fetch all holdings for all holders in the family
    // Use get_holder_holdings for each holder or a family-level aggregate query
    // If family-level RPC doesn't exist, call get_holder_holdings for each holder in parallel
    const holderResults = await Promise.all(
      holders.map(h => supabase.rpc('get_holder_holdings', { p_holder_id: h.id }))
    )
    const allHoldings = holderResults.flatMap(r => r.data ?? [])
    const familyTotalAum = allHoldings.reduce((s, h) => s + (h.current_value ?? 0), 0)
    const familyTotalInvested = allHoldings.reduce((s, h) => s + (h.total_invested ?? 0), 0)
    const familyGainLoss = familyTotalAum - familyTotalInvested
    const familyGainLossPct = familyTotalInvested > 0 ? (familyGainLoss / familyTotalInvested) * 100 : 0
    ```
