Create `app/api/goals/route.ts` with POST handler:
1. Parse body with Zod using CreateGoalSchema (see interfaces above)
2. Get supabase client, getClaims() → 401 if not authenticated
3. Verify the holderId belongs to a family the user owns (select from holders WHERE id = holderId AND family_id IN (SELECT id FROM families WHERE user_id = auth.uid()))
4. Insert into `goals` table: `{ holder_id, name, target_amount, target_date, assumed_cagr }`
5. If scheme_codes array non-empty: insert rows into `goal_holdings` table: `scheme_codes.map(code => ({ goal_id: goal.id, scheme_code: code }))`
6. Return `NextResponse.json({ goal }, { status: 201 })`
7. Catch validation errors → 400; auth errors → 401; DB errors → 500
