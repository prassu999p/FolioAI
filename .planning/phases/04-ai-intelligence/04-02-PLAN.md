  <behavior>
    computeAlpha:
    - fund with 6 months transactions, currentValue 150000, Nifty up 10% → returns positive decimal when fund grew more than nifty
    - fund with 2 months of data → returns null (insufficient)
    - empty transactions → returns null
    - reuses buildPortfolioCashflows + computeXIRR from lib/analytics/xirr.ts
    - nifty synthetic cashflows: same transaction dates/amounts, nifty units = amount / nifty_close on that date; terminal cashflow = nifty_units_total * last_nifty_close

    computeAUMTrend:
    - empty NAV history array → 'insufficient_data'
    - 2 data points → 'insufficient_data' (need at least 3)
    - AUM 6 months ago 100000, today 115000 (>10% increase) → 'growing'
    - AUM 100000, today 85000 (<-10%) → 'declining'
    - AUM 100000, today 103000 (within ±10%) → 'stable'
    - AUM is computed as nav * units; units parameter is current units (assumed stable across window)

    computeQualityScore:
    - alpha 0.05, expense_ratio 0.5 (very low), aum_trend 'growing' → score >= 80
    - alpha -0.03, expense_ratio 2.5 (high), aum_trend 'declining' → score <= 35
    - alpha null → treat as 0 for scoring purposes (apply 0 alpha contribution)
    - aum_trend 'insufficient_data' → treat as neutral (50/100 for that component)
    - always returns integer clamped 0-100
    - weights: alpha 50%, expense ratio rank 30%, AUM stability 20%
    - expense ratio ranking: < 0.5% = 100pts, 0.5-1.0% = 80pts, 1.0-1.5% = 60pts, 1.5-2.0% = 40pts, > 2.0% = 20pts; null = 50pts

    buildScorecardPrompt:
    - result includes fund_name
    - result includes qualityScore number
    - result contains "do not output" or "only write" or similar instruction to constrain Claude to prose only
    - result contains "SEBI" (disclaimer instruction)
    - result is non-empty string of >= 100 chars

    buildNarrativePrompt:
    - result includes holderName from context
    - result mentions total AUM formatted with ₹
    - result contains "SEBI" disclaimer instruction
    - result contains "may wish to consider" or "soft advisory" instruction
    - funds with alpha_pct < 0 appear in underperforming list in the prompt
    - result is non-empty string >= 500 chars

    buildChatSystemPrompt:
    - includes "FolioAI" framing
    - includes totalAUM formatted with ₹
    - includes XIRR when non-null
    - includes each holding's scheme_name and category
    - includes sectorExposure entries
    - includes active SIPs
    - includes "SEBI" disclaimer instruction
    - contains "never fabricate" or equivalent instruction
    - result >= 300 chars
