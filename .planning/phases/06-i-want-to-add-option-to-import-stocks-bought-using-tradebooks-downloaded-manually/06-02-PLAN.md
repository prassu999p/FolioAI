  - Unknown key preserved as-is (lowercased): normaliseHeaders({'Volume': '500'}) → {volume: '500'}

  - Row with all valid fields → {valid: true, data: ValidatedRow}

  - trade_type 'B' → normalised to 'buy'
  - trade_type 'buy' → normalised to 'buy'
  - trade_type 'purchase' → normalised to 'buy'

  - trade_type 'SELL' → normalised to 'sell'

  - quantity '-5' → {valid: false, errors includes positive number error}
  - trade_id is optional: row without trade_id → {valid: true}

Mapper cases:
  - mapToStockTransactionInsert(validRow, 'holder-uuid', 'batch-uuid', 'file.csv') → StockTransactionInsert with tradingsymbol = validRow.symbol
