1. Extend stock_holdings — add `source` column (new canonical field; `broker_source` kept for backward compat with existing Zerodha queries):
```sql
ALTER TABLE stock_holdings
  ADD COLUMN IF NOT EXISTS source TEXT NOT NULL DEFAULT 'zerodha'
    CHECK (source IN ('zerodha', 'manual', 'tradebook')),
  ADD COLUMN IF NOT EXISTS imported_at TIMESTAMPTZ,
  ADD COLUMN IF NOT EXISTS batch_id UUID,
  ADD COLUMN IF NOT EXISTS import_filename TEXT;
COMMENT ON COLUMN stock_holdings.broker_source IS 'Deprecated — use source column. Kept for backward compat.';
```

2. Create stock_transactions table for individual trade events (NOT positions):
```sql
CREATE TABLE stock_transactions (
  id              UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  holder_id       UUID NOT NULL REFERENCES holders(id) ON DELETE CASCADE,
  tradingsymbol   TEXT NOT NULL,
  exchange        TEXT NOT NULL CHECK (exchange IN ('NSE', 'BSE')),
  isin            TEXT NOT NULL,
  trade_date      DATE NOT NULL,
  trade_type      TEXT NOT NULL CHECK (trade_type IN ('buy', 'sell')),
  quantity        NUMERIC(16, 4) NOT NULL,
  price           NUMERIC(16, 4) NOT NULL,
  trade_id        TEXT,
  batch_id        UUID NOT NULL,
  import_filename TEXT,
  imported_at     TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  created_at      TIMESTAMPTZ NOT NULL DEFAULT NOW(),
  UNIQUE (holder_id, trade_id)
);
ALTER TABLE stock_transactions ENABLE ROW LEVEL SECURITY;
-- RLS: same three-hop chain as stock_holdings
CREATE POLICY "stock_transactions_select" ON stock_transactions FOR SELECT USING (
  holder_id IN (SELECT id FROM holders WHERE family_id IN (SELECT id FROM families WHERE user_id = auth.uid()))
);
CREATE POLICY "stock_transactions_insert" ON stock_transactions FOR INSERT WITH CHECK (
  holder_id IN (SELECT id FROM holders WHERE family_id IN (SELECT id FROM families WHERE user_id = auth.uid()))
);
CREATE POLICY "stock_transactions_delete" ON stock_transactions FOR DELETE USING (
  holder_id IN (SELECT id FROM holders WHERE family_id IN (SELECT id FROM families WHERE user_id = auth.uid()))
);
```

Apply migration to local Supabase: `npx supabase db push` (or `npx supabase migration up` if using local dev).

Create four modules in lib/tradebook/:

**lib/tradebook/tradebook-column-mapper.ts:**
Export `COLUMN_ALIASES` map (canonical key → set of raw header variations, case-insensitive) and `normaliseHeaders(rawRow: Record<string, unknown>): Record<string, unknown>`. Aliases must cover at minimum: symbol/Scrip Name, isin/ISIN Code, trade_date/Trade Date/Date, exchange/EXCHANGE, trade_type/Buy\/Sell/B\/S/buy_sell, quantity/Qty/QTY, price/Trade Price/Rate, trade_id/Trade ID/Order ID/Ref No.

**lib/tradebook/tradebook-parser.ts:**
Export `parseSpreadsheet(file: File): Promise<Record<string, string>[]>`. Uses `import * as XLSX from 'xlsx'`. Calls `XLSX.read(buffer, { cellDates: true, raw: false })`, gets first sheet, calls `sheet_to_json` with `{ defval: '', raw: false }`. Returns array of raw row objects. This module must NOT normalise columns — that is the mapper's job.

**lib/tradebook/tradebook-validator.ts:**
Export `TradebookRowSchema` (Zod schema) and `ValidatedRow` type. Schema validates: symbol (min 1), isin (min 1, 'ISIN required' message), trade_date (min 1), exchange (string, coerced to 'NSE' or 'BSE' by uppercasing), trade_type (string transform: 'b'|'buy'|'purchase' → 'buy'; 's'|'sell' → 'sell'; anything else → null, then refine null → error), quantity (coerce.number().positive()), price (coerce.number().positive()), trade_id (optional string). Export `validateRow(row: Record<string, unknown>): { valid: true; data: ValidatedRow } | { valid: false; errors: string[] }`.

**lib/tradebook/tradebook-mapper.ts:**
Export `StockTransactionInsert` interface: `{ holder_id, tradingsymbol, exchange, isin, trade_date, trade_type, quantity, price, trade_id, batch_id, import_filename }`. Export `mapToStockTransactionInsert(row: ValidatedRow, holderId: string, batchId: string, filename: string): StockTransactionInsert`. Maps `row.symbol` → `tradingsymbol`, `row.trade_date` → `trade_date` (ISO string), `row.trade_id ?? null` → `trade_id`.
