Request body (JSON):
```typescript
{
  holderId: string
  filename: string
  batchId: string  // UUID generated client-side
  rows: Array<{
    symbol: string; isin: string; trade_date: string; exchange: string
    trade_type: 'buy' | 'sell'; quantity: number; price: number; trade_id?: string
  }>
}
```

Route logic:
1. Auth check via `supabase.auth.getClaims()` — return 401 if unauthenticated
2. Zod validate the request body (holderId non-empty, rows non-empty array, each row matches ValidatedRow shape)
3. Verify the holderId belongs to this user's family (SELECT from holders WHERE id = holderId, then verify family belongs to user via RLS)
4. Insert into stock_transactions: map each row with `mapToStockTransactionInsert(row, holderId, batchId, filename)`. Upsert with `onConflict: 'holder_id,trade_id'` and `ignoreDuplicates: true`. Count how many were actually inserted (total minus duplicates).
5. Compute aggregated position from the rows just inserted (buy transactions only for net quantity and weighted avg price). For each unique (tradingsymbol, exchange) group: net_quantity = SUM(buy_qty) - SUM(sell_qty), weighted_avg_price = SUM(buy_qty * price) / SUM(buy_qty) for buy transactions only.
6. Upsert into stock_holdings with the exact pattern below. This is the CRITICAL guard that prevents corrupting existing Zerodha holdings:

```typescript
// CRITICAL: ignoreDuplicates: true means if a row already exists at
// (holder_id, tradingsymbol, exchange) — e.g. from Zerodha — we do NOT
// update it. We only insert net rows for stock symbols not yet in
// stock_holdings for this holder. Zerodha rows (source='zerodha') are
// never overwritten.
const holdingsToUpsert = aggregatedPositions.map(pos => ({
  holder_id: holderId,
  tradingsymbol: pos.tradingsymbol,
  exchange: pos.exchange,
  isin: pos.isin,
  quantity: pos.net_quantity,
  average_price: pos.weighted_avg_price,
  last_price: null,
  pnl: null,
  source: 'tradebook' as const,
  imported_at: new Date().toISOString(),
  batch_id: batchId,
  import_filename: filename,
}))

await (supabase as any)
  .from('stock_holdings')
  .upsert(holdingsToUpsert, {
    onConflict: 'holder_id,tradingsymbol,exchange',
    ignoreDuplicates: true,  // existing Zerodha rows are NEVER updated
  })
```

Why `ignoreDuplicates: true` here: if INFY already exists in stock_holdings for this holder (imported via Zerodha), the upsert does nothing. Only net-new stock symbols from the tradebook are inserted. This is the correct behavior — tradebook data is historical cost basis only, not a live position update.

7. Return JSON: `{ imported: number, skipped: number, batched: batchId }`

Error responses: 400 for validation failures, 401 for unauth, 500 for DB errors.

Use `(supabase as any)` for table operations per project pattern (postgrest-js v2.99.2 limitation with custom Database generics).

```typescript
export default async function StockHoldingsPage({
  params,
}: {
  params: Promise<{ familyId: string }>
}) {
  const { familyId } = await params
  const supabase = await createClient()

  // Verify family belongs to user (RLS will enforce, but 404 if not found)
  const { data: family } = await (supabase as any)
    .from('families')
    .select('id, name')
    .eq('id', familyId)
    .single()

  if (!family) notFound()

  // Fetch all stock_holdings for all holders in this family (all sources)
  const { data: stockHoldings } = await (supabase as any)
    .from('stock_holdings')
    .select('id, tradingsymbol, exchange, isin, quantity, average_price, last_price, pnl, source, imported_at, import_filename, holder_id')
    .in('holder_id',
      (supabase as any).from('holders').select('id').eq('family_id', familyId)
    )
    .order('tradingsymbol')

  return (
    <>
      <header className="flex justify-between items-center w-full px-8 py-4 sticky top-0 z-30"
        style={{ backgroundColor: '#f4faff' }}>
        <div className="flex items-center gap-4">
          <h2 className="text-xl font-bold tracking-tight font-headline" style={{ color: '#001736' }}>
            Stock Holdings
          </h2>
          <Link href={`/families/${familyId}/import?tab=tradebook`}
            className="text-sm font-semibold px-4 py-2 rounded-xl border"
            style={{ color: '#006d43', borderColor: '#c9e7f7' }}>
            <span className="flex items-center gap-2">
              <span className="material-symbols-outlined text-base">upload_file</span>
              Import Tradebook
            </span>
          </Link>
        </div>
      </header>
      <main className="px-8 py-6">
        <StockHoldingsTable holdings={stockHoldings ?? []} />
      </main>
    </>
  )
}
```
