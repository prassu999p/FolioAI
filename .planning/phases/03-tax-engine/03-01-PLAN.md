<objective>
Build the core tax computation library in pure TypeScript following the FIFO TaxLot pattern from research. This is the foundation all UI and API layers call.

Purpose: Rule-based deterministic tax calculations — never LLM.
Output: `lib/tax/` with engine, types, rules, FY utilities, and harvesting algorithm.
</objective>

<context>
@.planning/phases/03-tax-engine/03-CONTEXT.md
@.planning/phases/03-tax-engine/03-RESEARCH.md

**Key implementation notes from research:**
- TaxLot method: FIFO (First In, First Out)
- Grandfathering: MAX(actual cost, MIN(Jan 31 2018 NAV, sale price)) for pre-Feb 2018
- Equity holding period: ≥ 365 days = LTCG, < 365 = STCG
- Debt post-Apr 2023: always slab rate (Section 50AA)
- Rates: LTCG 12.5%, STCG 20%, exemption ₹1.25L
- Data from `transactions` table and `grandfathering_nav` table
</context>
