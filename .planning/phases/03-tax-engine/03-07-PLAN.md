**Part A — Create the export API route:**

Create `app/api/families/[familyId]/tax/export/route.ts` as a Next.js Route Handler.

The route accepts `?fy=prior` (defaults to current FY). It must:
1. Auth-check via `getClaims()` from `@/lib/supabase/server` — return 401 if no session
2. Fetch the same data as tax/page.tsx: holders for familyId, transactions via `get_holder_analytics_transactions` RPC (null start date for full FIFO history), grandfathering_nav table, nav table, funds table (scheme_code, scheme_name, category, isin)
3. Run `computeTaxSummary` per holder with the correct FY bounds
4. Collect all `realizedGains: RealizedGain[]` across holders
5. Build a CSV with these exact columns (Schedule CG format):
   ```
   Fund Name,ISIN,Purchase Date,Sale Date,Units Sold,Cost Basis (₹),Sale Value (₹),LTCG Amount (₹),STCG Amount (₹)
   ```
   For each RealizedGain:
   - Fund Name: from schemeNames map
   - ISIN: from funds table isin column (add isin to the select query)
   - Purchase Date: from the lot's purchaseDate — not directly on RealizedGain; use lotId to back-reference (or derive from realized gain data)
   - Sale Date: `gain.saleDate.toISOString().split('T')[0]`
   - Units Sold: `gain.soldUnits.toFixed(3)`
   - Cost Basis: `(gain.costBasis * gain.soldUnits).toFixed(2)`
   - Sale Value: `(gain.saleNav * gain.soldUnits).toFixed(2)`
   - LTCG Amount: `gain.classification === 'LTCG' ? gain.totalGain.toFixed(2) : '0.00'`
   - STCG Amount: `gain.classification === 'STCG' ? gain.totalGain.toFixed(2) : '0.00'`

   Note: RealizedGain does not directly store purchaseDate. Use the lot's purchaseDate by passing it through: the simplest approach is to include purchaseDate in each RealizedGain row. Since we cannot modify engine.ts in this plan, use the `holdingDays` and `saleDate` to back-calculate: `purchaseDate = new Date(gain.saleDate.getTime() - gain.holdingDays * 86400000).toISOString().split('T')[0]`

6. Return the CSV as a Response with headers:
   ```typescript
   new Response(csv, {
     headers: {
       'Content-Type': 'text/csv',
       'Content-Disposition': `attachment; filename="schedule-cg-${fyBounds.label}.csv"`,
     }
   })
   ```

The `funds` table needs `isin` in the select. If the column doesn't exist (Phase 1 schema may not have it), omit it and use scheme_code as fallback: `isin ?? String(gain.schemeCode ?? '')`.
